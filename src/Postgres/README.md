# Defra.Lis.Postgres

Npgsql and Entity Framework Core setup for PostgreSQL: read-write and read-only DbContexts, AWS IAM token generation, and the AddPostgresDatabase and UsePostgresDatabase extension methods.

Part of the Livestock Information Service (LIS). See the [repository README](https://github.com/DEFRA/lis-sdk-nuget-api-postgres#readme) for installation, configuration and usage.
